# media-skills

Claude Code skills for producing video and 3D visuals.

- `skill/` — **video-3d-production**: choose between Three.js, Blender/Cycles, AI video models or a hybrid, then build, render, assemble and verify. Symlinked into `~/.claude/skills/video-3d-production`.

Everything measured comes from one project (Ezekiel's wheels, Nov 2026). The AI-video guidance is research, not experience: it was never run.

Install: `ln -s "$PWD/skill" ~/.claude/skills/video-3d-production`
